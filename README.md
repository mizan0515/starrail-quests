# 스타레일 · 별의 기록

한국어 임무와 설정을 맥락으로 연결하는 독서 자료집입니다.

- 임무 종류 → 세계 → 챕터 → 임무 단계로 읽습니다.
- 설정집은 신앙과 질서, 영생과 전쟁, 도시와 기억, 생명과 지식으로 묶습니다.
- 편집자 해설에서 근거 원문으로, 원문에서 관련 해설로 이동합니다.
- Astro Starlight와 Pagefind로 제목·본문을 검색합니다.

사이트: https://mizan0515.github.io/starrail-quests/

게임 원문과 편집자의 해석을 구분합니다. 컷신 대사가 연결되지 않은 부분과 진행 순서의 확인 범위는 사이트의 수록 안내에 표시합니다. 게임 클라이언트 파일이나 개인 인증 자료는 포함하지 않습니다.
