# 임무와 연결 원문을 같은 독서 공간에서 읽기

임무 본문에서 연결 자료로 이동해도 현재 임무, 현재 원문, 실제 절 목차를 왼쪽에서 유지한다. 사용자가 제공한 독서판의 현재 기록 → 로컬 목차 → 같은 독서 경로의 기록 → 전체 탐색 구조를 기존 Starlight 독서 화면에 적용한다. 원문 페이지의 URL과 본문 앵커는 유지한다.

## 자료와 소속

`quest-reading-sources.ts`는 기존 연출 장면의 제목·URL·명시 소속·문구 역할과 개수만 읽는다. 본문·호출 근거·소유 관계를 복제하지 않는다. 기존 장면 목록의 순서와 임무별 목록을 보존하고, 검을 쟁기로에 명시 연결된 202196417 판본 비교를 목록 끝에 추가한다. 판본 비교는 두 수록본을 함께 읽는 자료이며 이전 문장의 현재 재생을 뜻하지 않는다.

따로 저장된 선택지 참조 840개를 기존 `timelineRows`로 포함한다. 선택지만 있는 네 자료도 한 문구로 표시한다. 대사, 화면 문구, 선택지 참조, 판본 원문은 각각 표시하고 중복 문구의 등장 횟수를 새로운 고유 본문 수로 합산하지 않는다.

확인된 임무 그룹은 640개다. 소속이 없는 연출 장면 79개와 일반 대화·설정 범위 참조는 현재 기록의 목차와 전체 탐색을 제공한다. 지역, 이름, 식별자, 방문 경로로 임무 소속을 만들지 않는다. 공동 호출 자료는 모든 확인된 임무를 표시하며, `from`의 임무가 확인된 소속 목록에 있을 때만 해당 묶음을 펼친다.

## 읽기와 복귀

`QuestReadingNav`는 현재 원문 → 실제 절과 장면 → 확인된 임무의 관련 자료 → 전체 탐색 순서다. 현재 원문의 목차는 렌더링된 제목·원문 절·출처 disclosure의 실제 앵커에서 만든다. 필터로 숨긴 장면은 현재 위치 표시에서 제외하며 목차 이동은 상위 접힌 절을 펼친다. 모바일 목차 이동은 기존 Starlight popover 메뉴를 닫고 본문 제목으로 포커스를 옮긴다.

본문의 `ContextPanel`과 reading-kit 상태 복구를 유지한다. 새 사이드바 링크는 고정된 별도 식별자를 쓰며 기존 본문의 자동 `reading-link` 식별자 순서를 바꾸지 않는다. 같은 `safeReadingReturn` 및 `sourceReadingOrigin` 계약으로 임무의 필터·앵커와 검증된 목록 복귀를 전달한다. 필터는 문서 재로딩 없이 바뀌므로 관련 자료를 클릭할 때 현재 주소를 다시 읽어 복귀 주소를 갱신한다. 새 원문은 기존 추가 원문 목록의 끝에 연결한다.

관련 자료는 종류별로 모으되 진행 순서로 표시하지 않는다. 사이드바는 각 종류의 현재 원문 주변 자료를 최대 8개 보여 주고 전체 임무 목록으로 연결한다. 임무의 추가 원문 목록은 모든 확인된 자료를 보존한다. 각 원문 페이지에 다른 원문 본문을 넣지 않아 전체 정적 산출물의 크기를 제한한다.

같은 임무 안에서 관련 자료 묶음의 펼침 상태와 왼쪽 메뉴의 읽기 위치를 세션 동안 유지한다. 기본 Starlight 상태 저장은 기본 탐색 트리의 배열 위치를 사용하므로, 커스텀 메뉴는 확인된 임무와 자료 종류의 고정 키를 사용한다. 이 상태는 메뉴 표시만 조정하며 임무 소속이나 본문 순서에 관여하지 않는다.

## 검증과 적용 범위

`node --test tools/test_quest_reading_navigation.mjs tools/test_quest_reading_nav_client.mjs tools/test_deep_catalogue_append_only.mjs src/lib/reading-kit/state.test.mjs`로 모든 기존 장면 URL·소속·임무별 순서, 840개 선택지 참조, 네 선택지 전용 자료, 화면 역할, 판본 소속, 79개 미소속 자료, 이웃 목록 상한, 잘못된 소속 선택, 판본·범위 복귀를 확인한다. 클라이언트 테스트는 실제 컴포넌트의 스크립트를 실행해 본문 목차, 모바일 메뉴 닫기, 포커스와 필터로 숨긴 장면의 위치 표시를 확인한다. 공유 reading-kit의 원본 URL 저장 및 문장 복귀 포커스 보존 테스트도 유지한다.

정적 모델 검증은 실제 브라우저 검증을 대신하지 않는다. 최종 빌드에서 원문·선택지·출처 게이트, 산출물 1GB 상한, 390px 모바일 메뉴, 키보드 목차·복귀, 임무 필터 유지, 공동 호출 및 미소속 자료, 판본 두 앵커, 두 사이트 reading-kit 해시 일치를 확인한다. 대표 임무는 서풍의 꽃바다, 검을 쟁기로, 검정(劍精), 이색 펫 연구·보살핌이다.
