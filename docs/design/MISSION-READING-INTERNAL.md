# 임무 본문과 출처 연결

공개 검증의 후속 수정: 설정 본문을 거쳐 원문으로 돌아오면 문장 위치는 유지되지만 원래 버전 목록의 검색 조건이 지워졌다. 복귀 주소는 같은 사이트의 원문 위치와 목록 주소 한 단계만 보존하며, 목록 내부의 추가 복귀 체인을 제거한다. 실제 1.0 목록의 1010203 검색 → 벨로보그 → 원문 → 목록에서 문장 포커스와 q/version을 확인한다.

같은 공개 브라우저에서는 새 임무 본문이 대사 9행·선택지 3개를 표시하는 동안 이전 reading-catalog.json 캐시가 목록을 ‘대사 연결 확인 중’으로 표시했다. 목록 API의 실제 JSON 바이트에 따른 내용 해시를 요청 주소에 붙이고, 40개 목록 화면의 해시 바인딩을 독립 QA로 검증한다. API 원문과 집계 데이터는 보존한다.

이번 변경의 독서 흐름은 버전별 목록 → 개별 임무 → 한국어 대사·선택지 → 출처와 설정 → 읽던 행 복귀다. 진행 목표는 대사 뒤의 접힘 영역에 배치한다.

원문의 문장·문단·장면 앵커를 보존한다. 임무 설정에 정확한 MainMissionID가 있고, 명시 JSON 경로·연출 식별자·유일한 이벤트 송수신으로 이어지는 자료를 주요 본문에 배치한다. 병합 임무는 canonical ID·missionParts·aliases의 정확한 멤버십을 출처와 연결한다. 폴더 번호만 일치하는 자료는 추가 대화 접힘 영역에서 보존한다. 주요 본문 배열은 확인된 참조 배열이며 실행 시간·분기 순서를 확정하지 않는다.

메시지는 MessageSectionID와 보존 문서를 연결하고 중복 표시를 제거한다. 같은 문서를 가리키는 복수 근거 중 명시 임무 근거를 우선한다. 메시지 1307000·1307100·1113500의 명시 근거가 후속 폴더 참조에 가려지는 실제 사례를 회귀 검사한다.

추출 안내 행은 원문 대사 수와 분리한다. 대사 누락 라벨·빈 본문과 함께, 정확한 ‘한국어 본문 미수록’ 안내/빈 hash/MessageItemConfig MainText·OptionText 출처의 조합을 gap으로 분류한다. 표시 문자열 자체는 보존한다.

공개 구조 자료는 DimbreathBot/TurnBasedGameData의 고정 commit 8b178dd48698e5e7b12f0cc319ddab149f2ffc5c다. 구조 참조와 JSON pointer를 얻으며 한국어 대사는 기존 로컬 추출본만 사용한다. 구조 archive 검증은 3676파일·28071귀속 chain을 확인했다. 추가 원문 17506행·3814장면·704임무는 기존 한국어 대사 ID와 정확히 대조했다. 로컬 보존 한국어 240078행은 변경 전후 비교로 확인한다.

현재 설치본 bootstrap 추출은 15파일·47항목·한국어0이다. 전체 한국어 DesignV와 일부 연출 자막 pack은 현재 입력에서 확인되지 않았다. 새 설치본 전체 대사의 재추출과 게임 전체 설정 편집 완성은 별도 미확인 범위다. 원문이 연결되지 않은 임무에 개요·자료 범위를 표시한다.

검증은 모든 임무의 주요/추가 본문 문자열·분류·숫자·앵커와 진행 목표 순서를 확인한다. 실제 브라우저에서는 버전 목록에서 원문을 발견하고 화자/선택지 필터·접힘 장면·배경 용어·원문 복귀·320px 읽기를 확인한다. 이 문서는 공개 생성 입력과 검색 색인에 포함되지 않는다.
