# 우주 콘텐츠·임무 대사 확장 검증

## 독서 흐름과 자료의 역할

버전별 임무 → 제목 검색 → 임무 본문 → 대사 원문 → 구조 참조와 대사표 → 읽던 목록으로 돌아가는 흐름을 연결했다. 기존 임무 원문과 대사표는 그대로 보존하고, 정확한 임무 구조 참조가 있는 대사를 보충 장면으로 추가한다. `reading-catalog.json`의 표시용 항목 수에는 보충 행을 포함하며 원본 `catalog.json`의 추출 항목 수는 보존한다.

`mission-dialogue-supplements.json`은 임무 ID → 구조 파일 → 정확한 참조 위치 → 로컬 한국어 원문 행으로 구성된다. 공개 구조 커밋 `8b178dd48698e5e7b12f0cc319ddab149f2ffc5c`는 식별자와 임무 귀속의 근거다. 한국어 본문·화자·해시·바이트 범위는 보존된 로컬 추출본에서 읽는다. 구조 파일 순서는 실제 대화 재생 순서와 구분한다.

집계는 554개 임무, 3,055개 보충 묶음, 12,921개 참조 행, 고유 대사 ID 12,412개다. 같은 원문 ID가 여러 구조 파일에서 참조된 경우 각 출처가 유지된다. `TalkSentenceID`, ID 목록, 정확한 `TalkSentence_N` 이벤트를 대조하며 숫자 범위는 임무 귀속의 근거로 사용하지 않는다.

## 질문별 읽기 묶음

우주 콘텐츠 7개에는 연구 설명·참여자의 발언·사물의 기록을 이어 읽는 입구가 있다. 28개 핵심 문서의 본문과 대사 596행을 보존한다. 곤충 떼 재난은 모의 연구와 번식의 기록을, 황금과 기계는 루버트 연산·컴퍼니 방문·기물을, 인지 불가 영역은 셉터·학파 전쟁·파티비아의 난제를 대조한다. 새 해설 3개는 각 서술자와 관측 범위를 표시하며 관계의 근거 인용으로 이동한다.

아이템·기물 3,597개는 제목과 전체 원문 본문으로 검색한다. 기물·아이템·유물·광추 분류는 검색 필터다. 같은 단어의 출현은 검색 결과로 표시하며 관계 해석의 근거와 구분한다.

## 화면과 공통 템플릿

공통 reading-kit 1.3.0의 목록은 분류 제목을 내용 위에 배치한다. 실제 독서 영역 너비를 기준으로 1~3열을 선택하여 좁은 화면의 빈 분류 열을 줄였다. 원문은 읽는 문장과 화자를 중심으로 배치하고 상세 출처는 키보드로 펼친다. 관계도·과정·순서·비교·포함 관계는 기존 공통 컴포넌트와 근거를 사용한다.

테마 선택의 아이콘·텍스트·화살표는 독립된 여백을 가진다. 972px에서 동일한 분류 열 너비와 테마 정렬을 확인했고 320px에서는 설정 목록·임무 대사·펼친 출처의 가로 넘침이 없다. Enter로 출처를 펼쳐 보이는 포커스를 확인했다. 원래 목록으로 복귀할 때 검색어와 버전이 유지된다.

참조 사례는 [V&A의 검색과 편집 탐색](https://www.vam.ac.uk/info/explore-the-collections/)과 [Cooper Hewitt의 연결된 역사](https://www.cooperhewitt.org/timeline/)다. 전체 자료 검색과 편집된 입구를 함께 제공하고, 자료·사건·인물 사이를 구체적인 제목과 원문 링크로 이동하는 방식을 적용했다.

## 검증과 원자료의 한계

현재 설치본의 SRMI·DesignV 카탈로그를 기존 바이너리 파서로 실제 재파싱했다. 확인된 카탈로그는 15개 파일·47개 항목이며 한국어 언어 항목 0개다. 전체 한국어 pack과 필수 표 항목이 없어 현재 설치본의 한국어 전체 재추출은 미확인이다. 240,078행은 해시·오프셋 provenance가 보존된 기존 게임 파일 추출본이다.

구조 archive를 다시 읽어 모든 보충 행의 JSON pointer와 원문 필드를 대조했다. 기존 원문 145,219문단, 전체 대사 240,078행, 인물 이야기 456개 보존 검사가 통과했다. 9,934개 HTML의 링크와 중복 앵커를 검사했다. 우주 페이지와 554개 임무의 보충 대사를 추가 대조한다.

기존 경로 715개는 고정 구조에서 발견되지 않았고, 참조 1,849개에는 해당 로컬 한국어 행이 없다. 타임라인 내부에서 참조 ID를 확인할 수 없는 컷신 자막은 이 복원 범위 밖에 있다. 스타레일의 이미지 블록은 현재 디코더로 확인되지 않아 공개 이미지에 추가하지 않았다. 모드별 원문 입구 확장과 전체 게임 콘텐츠 복원을 구분한다.

이 문서는 내부 검증 기록이며 독자용 페이지와 검색 색인 입력에 포함되지 않는다.
