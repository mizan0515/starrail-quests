# 잔여 미귀속 원문과 연출 원문 조사

2026-10-12 후속 요청은 이전 공개본의 정확 사용처 미확인 80,533개 대사를 전수 재판정하고, 기존 수록 밖의 연출 대사·선택지·화면 문구를 조사하는 것이다. 이번 수록은 실제 타입·필드·객체 참조·한국어 원문을 확인한 범위에 한한다.

## 고정 입력과 보존

- 이전 `dialogue-contexts.json` SHA-256: `5e6313bb34538b472be840ccce2448f07410974c2b4bfe4bd195da6e9df3adbf`.
- 구조 아카이브 SHA-256: `e1eee10139b338e271467e1823cedb0ceba0c5c1c608771f2386639db308f02a`, Dimbreath commit `8b178dd48698e5e7b12f0cc319ddab149f2ffc5c`.
- 설치본의 의미상 출시 버전은 미확인이다. 각 객체의 원본 블록·CAB·객체 해시와 공식 OSPRODWin4.6.0 한국어 표의 팩·엔트리 해시를 각각 보존한다.
- 기존 한국어 원문 240,078개와 감사 대상 156,915개를 유지한다. 기존 13,522개 사용 그룹, 91,024개 행, 94,136회 참조의 본문·화자·판본·상대 순서·원자료 위치·지역 근거를 독립적으로 대조한다.
- 기존 두 임무 Timeline 자료의 1,153개 식별자는 별도의 기존 독서 링크로 유지한다. 그중 고정 코호트에 속한 1,096개는 이미 읽을 수 있던 원문이며 새 본문 추가 수로 계산하지 않는다.

## 연출과 별도 원문

`deep-timeline-dialogue.json`은 10,439개 장면, 51,825회 원문 참조, 51,538개 고유 대사 ID를 담는다. 발화 49,272회, 화면 문구 552회, 비발화 선택지 참조 1,985회, 네이티브 선택지 16회를 구분한다. 같은 문구가 여러 연출에서 쓰이는 경우 각 실제 클립과 시작 시각을 유지한다.

실제 AssetBundle 컨테이너 → TimelineAsset → 부모 PPtr → 트랙 → 클립의 객체 경로와 전체 필드 EOF를 확인한다. 시작·길이는 유한한 숫자를 요구하며, 무한 후외삽 시간은 별도 메타데이터 문자열로 보존한다. 복수 임무가 호출하는 연출은 모든 검증된 소유 연결을 남긴다. 임무 연결이 없는 전투 연출 62개도 실제 원본 장면의 사용처로 제공한다.

전투 `BPTalkClip.TalkSentenceID` 159회/155개 ID 중 고정 코호트 132개를 추가 연결했다. Unity 접두 필드 길이에 따라 ID 바이트 위치가 달라지므로 단일 오프셋을 공통 규칙으로 사용하지 않는다. 독립 판독은 168개 전체 클립과 13,772개 잘린 입력, 336개 뒤붙은 입력, 336개 잘못된 ID 및 현재 원본 블록 14개를 확인했다.

`sdf-timeline-text.json`은 38개 연출의 화면 문구 185회/102개 문자열을 별도 자료로 담는다. `ShowSDFTextClip.Config.SDFTextID`는 `HeartDialSDFRow.ID`이며, 네이티브 테이블 별칭은 실제 정적 문자열 `HeartDialTalk`다. 해당 공식 팩의 전체 989행과 `SDFText`의 한국어 문자열 해시를 대조한다. 이 ID는 TalkSentenceID 분류에 포함하지 않는다. 화자를 추정하지 않는다. 기존 연출과 자산 키·루트 ID·원시 해시·바이트 위치/크기·CAB 해시가 모두 같은 19개 연출의 116행에는 기존 임무 소유 근거를 연결한다. 나머지 19개 연출의 69행은 임무 연결을 미확인으로 유지한다.

두 D/DS 구조에서 확인된 16개 선택지는 원래 옵션 배열·필드·바이트 범위를 유지한다. 그중 6개는 다른 연출에서 이미 연결된 ID로, 추가 고유 ID는 10개다. 선택 이후 재생 경로는 별도 근거가 필요하다.

## 직접 구조와 설정 참조

`PlayNPCSingleBubbleTalk`의 `TalkSentenceID.IsDynamic=false`와 정수 `FixedValue.Value`만 literal 대사 참조로 채택한다. 전체 구조 아카이브의 기존 540,886회 참조를 보존하면서 690회 wrapper 참조를 추가했다. 고정 코호트의 추가 연결은 2개다.

케이크는 네이티브 접근자가 실제 반환하는 `CakeConfigRow`의 `CatCaughtLines`·`CatMissedLines` 필드를 검증했다. 공식 팩의 전체 27행, 타입 메타데이터, 반환 타입, 선언 필드와 런타임 필드 오프셋, presence와 목적지 바이트를 확인한다. 108회 설정 참조 중 고정 코호트는 55개 ID/101회이며, 이전 연출과 겹친 1개를 제외한 신규 미확인 연결은 54개다. `NON_SPOKEN_CONFIGURATION_REFERENCE`와 “설정 참조”로 표시하며 실제 발화 시점은 확정하지 않는다. 본문 ID와 음성 ID가 다른 경우도 그대로 보존한다.

공개 원자료의 모든 `Hash` 값은 정수 정밀도를 잃지 않는 10진수 문자열로 투영하고, 원래 전체 행의 직렬화 문자열도 보존한다.

## 독서 경로와 검증

연출 목록은 `대화/연출-목록-N.html`, 개별 원문은 `대화/연출-timeline-<16자리 해시>.html`에서 읽는다. 목록의 검색·필터·확장 상태, 개별 문장 위치와 원래 대사표로의 이동·복귀를 유지한다. 확인된 임무에는 기존 본문 밖의 “연출 파일의 추가 원문”을 추가해 기존 장면·대사 수와 본문 순서를 보존한다. 출처·해시·바이트 범위는 접힌 근거에서 확인한다.

독립 검증은 보존 한국어 파일 369개와 새로운 literal 클립 51,809개, 트랙 10,893개, 소유 구조의 실제 포인터를 재생한다. SDF는 별도 네이티브 클립 185개와 27,491개 잘못된 바이너리 입력, 13개 잘못된 공개 식별자/원문/화자/소유 입력을 검증한다. 전체 `Test-PrValidationGate.ps1`에 연출·SDF 원문 및 HTML 검증, 읽기 복귀와 공개 원본 복원 검증을 연결한다.

## 남은 해독 경계

지원 가능한 D/DS 네이티브 구조 961개는 전체 EOF와 공개 구조의 비열거형 필드를 대조했다. 남은 2,821개 참조는 최초 미지원 필드에서 중단되며 그 뒤 숫자를 대사로 탐색하지 않는다. 공개 구조가 없는 일부 지원 구조는 별도의 네이티브 선택지 원문으로 보존한다.

`PlayMissionTalk` 시작·끝점 21개는 실제 TalkSentence 소비 경로가 입증되지 않아 내부 숫자 범위를 펼치지 않는다. MusicRhythmBoard·MusicFes와 Fate 자막·RecordingUI는 후보 소비 경로와 실제 호출 인자의 연결이 부족한 경계를 보존한다. 기존 코호트의 미확인 39,842개는 미사용·삭제된 내용으로 판정하지 않는다. 한국어 본문·화자·음성의 판본이 일치하지 않은 Timeline 후보도 수록에서 보류한다.

후속 경계는 issue #20에서 유지한다. 미지원 원본을 보존하고, 새 타입·소비 함수·객체 소유 근거가 생겼을 때 같은 입력 해시로 다시 조사한다.


## 공개 용량과 동등성

공개 사이트의 10억 바이트 한도를 유지하며 새 원문을 제공한다. 정적 원문 본문·화자·앵커·원래 링크·원문 JSON 다운로드·읽기 자료를 보존한다. 접힌 기술 근거의 내부만 실제 gzip과 고정 inflate codec으로 복원하고, 동일한 공통 화면 코드·기술 근거를 공유한다. 빌드 전 HTML/CSS/JS의 정확한 SHA로 전체 역변환을 검증한다. codec과 MIT/Zlib 라이선스는 사이트에 포함한다.

각 용어 링크의 중복 인용문 속성은 원문 문단의 `textContent.slice(0,220)`에서 읽도록 바꾼다. 기존 16,254파일의 79,838문단·92,922속성을 UTF-16 단위로 전수 비교해 차이0개를 확인했다. 줄바꿈 3,604문단, 앞쪽 공백12문단, 취소선2문단도 포함한다. 실제 화면에서 팝업 인용문과 원문 복귀를 검증한다.

신규 연출·SDF·귀속 파일에는 `.gitattributes`로 바이트 변환을 금지하여 플랫폼별 줄바꿈 변환이 입력 해시를 바꾸지 않도록 한다.
