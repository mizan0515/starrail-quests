# 도감과 추가 원문의 관찰 범위

독자는 새로 확인한 자료를 기존 서적·인물·아이템 자료실에서 찾고, 종류별 도감 목록에서도 찾을 수 있다. 같은 이름의 적 기록을 하나의 생물 종으로 합치지 않는다. 목록 카드는 제목이 같은 항목을 묶고, 본문은 실제 표 ID별로 보존하며 다른 변형으로 이동하는 링크를 제공한다. 축복과 운명의 길 메아리가 같은 등록 자료에 있으므로 자료 종류는 **축복·메아리 원문**이다.

## 추가한 원문

공식 4.6 표에서 확인한 새 서적은 18권이다. 이 가운데 17권은 새 모음 831~847에, 192195는 기존 모음 647 『연지의 기록 개구리편』의 추가 권에 연결된다. 기존 모음의 네 절과 문장 앵커는 보존하고 마지막에 새 절을 추가했다. StoryAtlas에 새로 나타난 AvatarID1503의 이야기 다섯 개는 고정된 AvatarConfig의 AvatarName 해시와 공식 한국어 문자열의 정확한 연결로 표시 이름 **펄**을 붙였다. 원문의 인물 ID와 표시 이름의 별도 구조 근거를 구분한다.

새 광추 『내일에 바치는 색채』의 설명과 배경 이야기, 실제 다른 본문을 가진 아이템 23개, 새 LoadingDesc의 설정 네 개와 시점 전환 안내 한 개도 추가했다. 광추와 물품은 기존 우주·아이템 목록에서 찾을 수 있다. 명칭만 있거나 기존 수록 본문과 동일한 새 표 변형 1,295개는 별도 sourceOnlyRecords로 보존하고 추가 독서 카드는 만들지 않는다. 기존 서적과 인물의 같은 ID에서 관찰된 본문 변화는 이번 추가에 적용하지 않았다.

고정 구조의 업적 1,950행, 이름과 설명이 모두 한국어에 연결된 적 기록 2,720행, 명시된 ID·레벨로 연결된 축복·메아리 1,294행을 별도 문서로 보존했다. 새 문서는 6,011개이며 기존 서적 모음 하나를 확장한다. 원문 행 8,108개는 표시한 필드 개수다. 문서 수·표 행 수는 서로 다른 생물 종의 수나 현재 게임 도감의 완성 수가 아니다.

## 원천과 변환

기존 20개 표 스키마를 공식 4.6 DesignV의 정확한 엔트리에 적용해 필드와 EOF를 확인했다. 적·업적·축복·메아리의 구조는 커밋 `8b178dd48698e5e7b12f0cc319ddab149f2ffc5c`에 고정한 자료이고 한국어는 별도 공식 4.6 TextMap이다. 이 둘의 관찰 버전을 합쳐 현재 설치본의 표 구조·현재 도감 전체 목록으로 표현하지 않는다.

각 필드는 표 이름·행·필드 포인터, 실제 문자열 해시, 한국어 원문 바이트 위치, 원문과 표시문을 보존한다. section의 record는 JavaScript에서 큰 정수를 잃지 않도록 문자열화한 공개 투영이다. `recordProjectionSha256`는 이 공개 record를 재현하는 SHA-256이고 `sourceRecordSha256`는 문자열화 전 typed 원본 행의 SHA-256이다. 원자료 재실행은 두 계약을 각각 대조한다.

BookSeriesID, AvatarID 이름 주석, Achievement.SeriesID, MonsterTemplateID, 축복 등록 표의 (MazeBuffID, MazeBuffLevel) 연결만 사용한다. 이름이나 숫자 접두사를 소유 관계로 사용하지 않는다. RogueMazeBuff1469행 ID617000의 Lv가 생략되어 기본 레벨을 넣지 않았다. RogueBuff90행은 명시한 ID·레벨 대상이 없어 별도 미연결 자료로 남겼다. 적의 이름 한 필드와 다른 적의 설명 한 필드는 공식 한국어 해시와 일치하지 않아 문서 생성에서 제외했다.

NBSP·줄바꿈·지원된 게임 서식의 표시 정리는 기존 readable 경로를 사용한다. 새 서적 832·833의 `<s>` 원문은 raw에 보존하고 표시문에서는 태그를 제거한다. 원문이 지정한 취소선 범위를 코드 포인트 구간으로 저장하고 본문에서 안전한 `<s>` 요소로 표시한다. 카드·검색에는 태그 문자열을 넣지 않는다. 수치 자리표시와 ParamList는 보존하고 검증하지 않은 수치 대입을 수행하지 않는다.

## 보존과 독서 흐름

공개 sidecar와 확인된 manifest를 기존 restore_dataset 경로에서 검증한 뒤 data로 복원한다. 기존 catalog·documents·dialogues·explorer·aliases는 수정하지 않는다. 합성 catalog와 문서 view에서 새 문서를 추가하고 모음 647에 새 절을 붙인다. 검색 색인과 source graph는 합성 view를 소비한다. 본문에서 같은 제목의 모든 변형으로 이동할 수 있으며 목록의 검색어·그룹·확장 상태·항목 앵커를 읽던 위치로 유지한다.

원자료 재실행, 공개 artifact 검사, HTML 검사는 서로 다른 검증이다. 원자료 검사는 실제 캐시와 고정 archive가 필요하다. 공개 artifact 검사는 clean checkout에서 복원된 데이터만으로 실행할 수 있다. HTML 검사와 자동 테스트가 모바일 레이아웃·실제 키보드·복귀 동작을 대신하지 않으며 최종 실제 화면 검증은 별도로 수행한다.
