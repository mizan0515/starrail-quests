# 세력·위협과 초기 버전의 연결

반물질군단은 나누크의 군대와 파멸의 정의를 연결한다. 약왕의 비전은 조직의 목적, 풍요의 백성의 정의, 선주 연맹의 활동을 대조한다. 같은 신앙을 언급한다는 이유로 서로 다른 집단을 하나의 조직으로 합치지 않는다.

스텔라론 헌터는 카프카의 소속 기록에서 시작해 나부의 「궁극의 탐구, 역사의 장관」 scene-14를 읽는다. 열차를 인도하고 연맹의 도움을 얻으려는 계획은 카프카의 발언이다. 순서 템플릿은 그 발언에 담긴 계획을 표현하며 미래의 사건을 완료된 사건으로 표시하지 않는다.

스텔라론은 열계의 정의와 우주정거장의 수용체 계획을 잇는다. 전체 인용은 로컬 한국어 자료에 유지하며 연결마다 문서·장면·문자열 해시를 기록한다. 새 본문 4개는 기존 공통 reading-kit의 관계·순서·비교·출처 컴포넌트를 사용한다.

임무 버전은 공개 생산 버전 MainMission 표 31개를 고정 커밋과 SHA-256으로 대조한다. 1.0~2.5는 iam-akuzihs/StarRailData의 보관 기록이며 2.6 이후는 기존 TurnBasedGameData 기록이다. 최초 표 수록과 실제 공개를 별도 필드로 보존한다. 공개가 확인된 1.1 동행 임무 4개 제목은 로컬 진행 조각 8개에 연결된다. 인터넷에서 한국어 대사나 설정 본문을 가져오지 않는다.

QA는 전체 원문·링크·관계 근거 검사와 verify_mission_versions.py를 사용한다. 표에 먼저 수록될 수 있는 임무가 출시 확인 집합에 자동으로 들어가지 않는 사례도 확인한다. 초기 통합 URL early.html은 1.0~2.6을 함께 읽는 경로로 보존한다.

편집 경로는 22개다. 전체 세계관의 수동 편집 완료와 구분하며, 자료 원문 전체는 기존 검색과 목록에서 읽을 수 있다.
