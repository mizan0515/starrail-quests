# 스타레일 한국어 자료집 디자인

목표: 다시 읽을 임무를 찾거나 설정의 관계를 이해하고, 설명에서 근거 원문으로 자연스럽게 이어진다.

- 첫 화면에서 임무 목록과 설정 주제에 바로 진입한다. 임무 종류 → 세계 → 챕터를 고정된 탐색 순서로 쓴다.
- 설정집은 질문 중심의 편집자 해설, 관계 표, 추천 읽기 순서, 근거 원문으로 구성한다. 해설과 게임 원문을 명확히 구분한다.
- 원문을 보존한다. 내부 ID·파일 경로·조건은 접힌 출처에 둔다. 추정은 확정된 사실처럼 표시하지 않는다.
- 임무 순서는 출처의 선행 조건과 진행 참조에 따른다. 선택/병렬 단계는 별도로 표시한다. 미확인 순서는 정렬을 플레이 순서로 주장하지 않는다.
- 종이색 배경, 진한 잉크색 글자, 절제된 청록 강조. 긴 한국어 본문은 65자 안팎 너비, 1.85 줄간격. 제목·요약·본문·보조 정보의 차이를 크기와 여백으로 만든다.
- 키보드 탐색, 보이는 포커스, 네이티브 select, 의미 있는 제목, 44px 터치 영역, 충분한 대비. 모바일에서는 본문 한 열, 메뉴와 목차 접기.
- 검색은 제목과 본문을 함께 찾는다. 빈 목록과 연결하지 못한 본문은 이유와 돌아갈 경로를 제공한다.
- PDF/CSV 같은 작업용 자료를 기본 독서 화면에 노출하지 않는다. 원문 인용 위치와 수록 범위는 항상 찾을 수 있게 한다.

## 독서 화면 보완

- Pretendard Variable v1.3.9, SIL OFL 1.1. 고정된 jsDelivr 글꼴 CSS를 사용하고 실패 시 한국어 시스템 글꼴로 즉시 표시한다. 본문을 글꼴 로딩에 숨기지 않는다.
- 기본 18px, 모바일 17px. 본문·인용문은 18~19px 상당, 보조 설명도 14px 이상. 밝은 테마의 본문은 진한 남색, 어두운 테마는 밝은 회백색이다.
- 설정 주제는 세계명 → 질문 → 연결해서 읽는 흐름 → 근거 원문 순으로 보여준다. 카드 안에서는 해설의 흐름을 표시하고, 원문 근거를 확인할 수 있는 동작을 명시한다.
- 버전은 ID를 해독해서 추측하지 않는다. 공개 프로덕션 버전 표의 최초 등장 시점이라는 의미를 노출한다. 초기 스냅샷의 임무는 이전 버전 미확인으로 보존한다.
- 모션은 카드 호버와 제어 피드백에만 짧게 적용하며, 본문은 처음부터 보인다. reduced-motion에서는 움직이지 않는다.
